## Prerequisites

- macOS or Linux. basalam uses Salam's POSIX terminal support.
- The Salam compiler, version 0.5.5 or later. Check with `salam version`.

<Steps>
  <Step title="Install Salam">
    Run the official installer, then confirm the compiler is on your `PATH`.

    ```bash
    { curl -fsSL https://raw.githubusercontent.com/SalamLang/Salam/refs/heads/main/install.sh || wget -qO- https://raw.githubusercontent.com/SalamLang/Salam/refs/heads/main/install.sh; } | sh
    salam version
    ```
  </Step>
  <Step title="Add basalam to your project">
    Salam has no package registry for third-party libraries yet, so you vendor the source. A git submodule keeps it updatable.

    ```bash
    git submodule add https://github.com/curedbylethe/basalam vendor/basalam
    ```

    The library itself is the `basalam/` directory inside the repository.
  </Step>
  <Step title="Write a program">
    One `include` line pulls in the whole library. The path is relative to the file that contains it.

    ```salam main.salam
    import term

    include "vendor/basalam/basalam/basalam.salam"

    struct Hello:
        pub use basalam.BaseWidget

        pub func render(buf: basalam.Buffer, bounds: basalam.Rect):
            buf.put_str(2, 1, "Hello from basalam!", term.Sgr(term.StyleBold))
            buf.put_str(2, 3, "Screen size: " + bounds.width + "x" + bounds.height, "")
            buf.put_str(2, 4, "Press q to quit.", "")
        end
    end

    func main:
        mut screen := basalam.NewTerminalScreen(Hello {})
        screen.start()
        defer screen.close()

        screen.present()
        mut ev := basalam.Event {}
        until screen.next_event(ev):
            if not screen.dispatch(ev) and ev.is_char("q"):
                screen.stop()
            end
            screen.present()
        end
    end
    ```

    Salam loads every `.salam` file in `basalam/` as one package because the directory name matches the entry file `basalam.salam`.
  </Step>
  <Step title="Build and run">
    ```bash
    salam build main.salam
    ./main
    ```

    The terminal switches to a full-screen view. Press `q` and your shell comes back exactly as it was.
  </Step>
</Steps>

## What just happened

- `Hello` embeds `BaseWidget`, so it is a widget. It only overrides `render`.
- `NewTerminalScreen` makes `Hello` the root widget, sized to the terminal.
- `start()` switches the terminal to raw mode and the alternate screen and starts the input thread. `defer screen.close()` undoes all of it on every exit path.
- The `until` loop takes one event at a time. `dispatch` offers it to the widgets; `q` is not consumed by any widget, so the loop stops the screen.

Read [The event loop](/concepts/event-loop) for the details, or [Writing a widget](/guides/writing-a-widget) to build an interactive one.

## Run the demo

The repository ships a larger demo with panels, ticks, resize handling, and focus movement (Tab and the arrow keys):

```bash
git clone https://github.com/curedbylethe/basalam
cd basalam
make run
```

## Work on basalam itself

From a clone of the repository:

```bash
make check
```

`make check` runs the formatter check, compiles the library, and runs the test suite. Run `make help` for the other targets.
