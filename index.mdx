basalam is a library for building terminal user interfaces in [Salam](https://github.com/SalamLang/Salam), a statically typed systems language that compiles to native executables. You import it into your own program; it is not an application.

It sits on top of Salam's standard `term` package. `term` already handles raw mode, escape sequences, colors, and key decoding. basalam adds the parts a full-screen application needs on top: geometry, widgets, events, focus, and a screen that draws frames.

<Note>
  basalam is at version 0.1.0 and under active development. This release covers the core (epic 1), the concrete widgets (`Text`, `Input`, `List`, `Button`, `Checkbox`, `Progress`, `Table`, `Modal`, and `Separator`), the layout engine (`Row`, `Column`, `Grid`, and `Stack`), and an opt-in keymap with `NewDefaultKeymap`. More widgets are planned for later releases.
</Note>

## Design in brief

- **Retained mode.** Widgets are long-lived values. Your application changes their state; the screen redraws them.
- **Only input is asynchronous.** One background thread reads the terminal and produces events. Your widgets handle them synchronously on the main thread, so they need no locks.
- **Widgets are interfaces.** Anything with the nine `Widget` methods is a widget. Embed `BaseWidget` and override only what you need.
- **Widgets draw into a buffer, never the terminal.** That keeps rendering testable without a terminal.
- **Two focus models.** Tab-style linear order and arrow-key spatial navigation, as methods your application calls. The opt-in keymap (`NewDefaultKeymap`) wires up `Tab` and the four arrows for you, with no imposed bindings and no modes of its own.
- **Geometry on the cell grid.** Every position is an integer cell coordinate, 0-based, with half-open rectangles.

## Status

| Area | State |
| --- | --- |
| Geometry (`Rect`, `Point`) | Available |
| `Widget` interface and `BaseWidget` | Available |
| `Text` widget | Available; the first concrete widget |
| `Input` widget | Available; single-line text entry |
| `List` widget | Available; single-selection scrollable list with vim navigation |
| `Button` widget | Available; one-row action button with Enter, Space and click activation |
| `Checkbox` widget | Available; one-row boolean toggle with Space and click toggling |
| `Progress` widget | Available; one-row buffer-drawn progress bar with a percent tail |
| `Table` widget | Available; non-focusable grid of rows with column widths, a header and alignment |
| `Modal` widget | Available; overlay dialog over a dim scrim, with focus isolation and Esc |
| `Separator` widget | Available; one-line horizontal or vertical rule drawn in one rune |
| Layout engine (`Row`, `Column`, `Grid`, `Stack`) | Available; containers assign their children's bounds |
| `Event` type, helpers, and bubbling dispatch | Available |
| Widget tree with integer IDs | Available |
| `Screen`: event loop, input thread, resize, ticks | Available |
| Focus: stack, linear, and spatial navigation | Available |
| Keymap: opt-in key bindings with scopes and sequences | Available; install with `set_keymap`, defaults via `NewDefaultKeymap` |
| `Buffer` (double-buffered) | Available; a consumed event repaints the widget that consumed it, and flush writes the touched cells that differ |
