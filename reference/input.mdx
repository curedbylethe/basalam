`Input` draws a single-line text field into a [buffer](/reference/buffer). It holds a value, a caret into that value, an optional placeholder, and the styles for the value, the cursor cell, and the placeholder. It is focusable, so the [screen's focus dispatch](/concepts/focus) routes keyboard events to it while it is focused.

```salam
mut in := basalam.NewInput()
in.set_placeholder("Search")
in.set_bounds(basalam.Rect { width = 20, height = 1 })
```

## Input

`Input` embeds [BaseWidget](/reference/widget), overrides the default `render`, and adds `focusable`, `handle_event`, `value`, `set_value`, and `set_placeholder`; it inherits `bounds` and `set_bounds` unchanged.

```salam
pub struct Input:
    pub use BaseWidget

    pub placeholder: str = ""
    pub style: Style = StyleDefault
    pub cursor_style: Style = Style { reverse = true }
    pub placeholder_style: Style = Style { fg = BrightBlack }
    pub max_length: int = 0
    pub filter: func (str) bool = (candidate: str): ret true end
    pub masked: bool = false
    pub mask_glyph: str = "*"
    pub on_submit: func (str) bool = (value: str): ret true end
end
```

<ResponseField name="placeholder" type="str">
  Text shown (dim) while the value is empty. `""` means no placeholder.
</ResponseField>

<ResponseField name="style" type="Style" default="StyleDefault">
  The base [`Style`](/reference/style) of the value and the blank background. `StyleDefault` leaves both colours at the terminal's default.
</ResponseField>

<ResponseField name="cursor_style" type="Style" default="Style { reverse = true }">
  Merged over `style` for the cursor cell, so reverse video by default.
</ResponseField>

<ResponseField name="placeholder_style" type="Style" default="Style { fg = BrightBlack }">
  Merged over `style` for the placeholder, so bright black by default.
</ResponseField>

<ResponseField name="max_length" type="int" default="0">
  Maximum value length in glyphs. `0` means unlimited. See [Shaping](#shaping).
</ResponseField>

<ResponseField name="filter" type="func (str) bool" default="accepts everything">
  Called with the whole candidate value after a proposed insertion. `false` rejects it.
</ResponseField>

<ResponseField name="masked" type="bool" default="false">
  Paints every value glyph as `mask_glyph`. Display only.
</ResponseField>

<ResponseField name="mask_glyph" type="str" default='"*"'>
  The glyph painted per value glyph while masked. `""` means `"*"`.
</ResponseField>

<ResponseField name="on_submit" type="func (str) bool" default="returns true">
  Called on `Enter` with the real value. Its return value is the consumed flag. See [Submit](#submit).
</ResponseField>

The first three are complete style values. `StyleDefault` on `style` asks for the terminal's default; on `cursor_style` or `placeholder_style` it adds nothing, which is how you ask for a plain cursor or placeholder. There is no `""` sentinel: an empty string used to mean "use the built-in default", and a zero style now means "add no styling".

The value and the caret are counted in codepoints, so a multibyte glyph is one cell and one caret step. The caret is always an index between `0` and the value's length. It moves with the arrow keys, `Home`, and `End`, and edits happen at it.

### Methods

```salam
pub func NewInput(): Input
pub func value(): str
pub func set_value(v: str)
pub func set_placeholder(p: str)
```

| Method | Description |
| --- | --- |
| `NewInput(): Input` | Creates an empty input with no placeholder and the default cursor and placeholder styles. |
| `value(): str` | The current text, without styles. |
| `set_value(v: str)` | Replaces the value, cut to `max_length` glyphs when that is set, without calling `filter`. The caret moves to its end. |
| `set_placeholder(p: str)` | Sets the text shown while the value is empty. |

## Keyboard

`Input` is focusable, so key presses reach it through dispatch while it is focused. `handle_event` reacts as follows:

| Key | Effect | Consumed |
| --- | --- | --- |
| A printable character | Inserted at the caret; the caret moves after it. | Yes |
| `Space` | Inserts one space at the caret. | Yes |
| `Left` / `Right` | Moves the caret one codepoint. At the start or end, nothing changes. | Yes |
| `Home` / `End` | Moves the caret to the start or the end. | Yes |
| `Backspace` | Deletes the codepoint before the caret. At the start, nothing changes. | Yes |
| `Delete` | Deletes the codepoint at the caret. At the end, nothing changes. | Yes |
| `Enter` | Calls `on_submit` with the value. | The callback's result (`true` by default) |
| Anything else (`Tab`, `Escape`, `Up`, `Down`, `PageUp`, `PageDown`, `Insert`, function keys) | Nothing. | No — the event bubbles to ancestors |

A character typed with `Ctrl` or `Alt` held is not a plain character, so it is not appended and bubbles like any other unhandled key. Mouse, resize, and tick events are ignored and bubble too.

## Submit

`on_submit` is called synchronously from `handle_event` when `Enter` is pressed, with the real value (never the mask, even when `masked`). Its return value decides what happens to the key:

- **`true`** (the default): `Enter` is consumed.
- **`false`**: `Enter` is not consumed and bubbles to the parent, so a form can pass it on.

The callback runs only for `Enter`, never for other keys, a rejected edit, or focus loss. Input does not clear, blur, or move the caret itself. If the callback calls `set_value` or changes `max_length`, the caret and window are clamped to the new value afterwards; the callback is not called again.

A keymap binding on `Enter` cannot replace `on_submit`: widgets get keys before the keymap, so a focused `Input` handles `Enter` first.

```salam
mut name := basalam.NewInput()
name.on_submit = (v: str): ret v == "" end // an empty value lets Enter bubble
```

## Shaping

`max_length`, `filter`, and `masked` shape what the value can hold and how it paints. The defaults leave the widget unchanged.

- **Order.** A typed glyph is checked against `max_length` first, then passed to `filter`. If either rejects it, the key is still consumed and nothing changes: no bell, no caret move.
- **Glyph unit.** `max_length` counts glyphs (codepoints), like the caret and `value()`, not display cells.
- **Insertions only.** `filter` receives the whole candidate value after one proposed insertion. It is never called for `Backspace`, `Delete`, or `set_value`, so a user can always delete their way out of a bad value.
- **`set_value`.** A value longer than `max_length` is truncated to its first `max_length` glyphs. `filter` is not called.
- **Masking.** With `masked`, every glyph paints as the first codepoint of `mask_glyph`. The value, caret, and window are unchanged, and `Home` and `End` work as usual. An empty value shows the placeholder, never the mask.
- **ASCII.** When the buffer's glyph policy is `GlyphPolicy.ASCII`, a non-ASCII mask glyph paints as `*`.

```salam
mut pin := basalam.NewInput()
pin.max_length = 4
pin.masked = true
pin.filter = (c: str): ret c.len() == str.CharCount(c) end // ASCII only
```

## Cursor

While the buffer reports focus, `Input` marks the caret with one reverse-video cell (`ESC[7m`). The cell covers whatever the row already has at that column — the glyph under the caret, the blank after the last glyph, or the first placeholder character when the value is empty. Its style is `StyleMerge(style, cursor_style)`; the placeholder's grey is dropped from that one cell, so the cursor stays a solid reverse-video block over it.

This is a cell style, not the terminal's own cursor. The screen keeps the real cursor hidden, so the field draws its own. Set `cursor_style` to replace the default reverse:

```salam
in.cursor_style = basalam.Style { fg = basalam.Black, bg = basalam.White }
```

The merge keeps the attributes you set on `style`; the colours you put on `cursor_style` win over the base ones. Assign `basalam.StyleDefault` for a cursor that adds nothing to the base style.

An unfocused input draws no cursor cell.

## Placeholder

The placeholder is shown whenever the value is empty, focused or not. It is styled bright black by default — `Style { fg = BrightBlack }`, which emits `ESC[90m` — through `StyleMerge(style, placeholder_style)`, and it is hard-clipped at the field width: characters past `width` are not drawn.

- The placeholder never becomes part of the value, so `value()` stays `""` while only the placeholder is visible.
- Backspacing the last character brings the placeholder back.
- Set `placeholder_style` to style it differently.

```salam
in.set_placeholder("Search")
println in.value() // "" while the field is empty
```

## Focus

`focusable()` returns `true`, so the screen's focus dispatch delivers key presses to the input while it is focused, and Tab-style and spatial navigation can move the focus onto it. An unfocused input receives no key events. When the input consumes a key, the screen marks itself dirty and redraws, so the caret and the value stay in step with the terminal.

## Overflow

The field shows the full width; no cell is reserved for the caret. `Input` stores the index of the first visible codepoint, `start`, between frames and moves it only when the caret leaves the window:

```text
if caret < start:                    start = caret
else if caret > start + width - 1:   start = caret - width + 1
```

The caret column is `caret - start`, always between `0` and `width - 1`. The window shows the codepoints from `start` up to `min(count, start + width)`, where `count` is the value's length. Focus does not change the window; an unfocused field draws the same cells without the cursor.

Worked example, width `8`, value `"abcdefghij"` with the caret at the end:

| State | Shown | Cursor column |
| --- | --- | --- |
| Focused | `defghij` and a blank | `7` |
| Unfocused | `defghij` and a blank | — |

Press `Home` and `start` becomes `0`: the row shows `abcdefgh` with the cursor on `a`.

## Example

A buffer is plain memory, so you can render and inspect an input without a terminal:

```salam
import term
include "basalam/basalam.salam"

func key(seq: str): basalam.Event:
    ret basalam.Event { kind = basalam.KeyEvent, key = term.Decode(seq) }
end

func main:
    mut inp := basalam.NewInput()
    inp.set_placeholder("Name")
    _ := inp.handle_event(key("A"))
    _ := inp.handle_event(key("b"))
    _ := inp.handle_event(key("\x7f")) // backspace drops "b"
    _ := inp.handle_event(key("c"))
    println inp.value() // Ac

    mut buf := basalam.NewBuffer(6, 1)
    defer buf.free()
    buf.focused = true
    inp.render(buf, basalam.Rect { width = 6, height = 1 })
    println "[" + buf.row_text(0) + "]" // [Ac    ]
    println basalam.StyleEq(buf.get(2, 0).style, basalam.Style { reverse = true }) // true: the cursor cell is reversed
end
```

<Note>
  A `dyn basalam.Widget` cannot be downcast back to an `Input`. Keep a concrete `Input` reference — or a shared location such as a `mut` global — to call `value()`, `set_value`, and `set_placeholder`.
</Note>
